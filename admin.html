1. Konten Website

Anda dapat mengubah semua tulisan dan artikel melalui editor JSON. Artikel blog berada pada bagian blog.items, dalam format [kategori, judul]. Gunakan tanda kutip ganda dan koma JSON dengan benar.

3. Kelola Artikel dengan Mudah

Tambahkan, ubah, atau hapus artikel melalui formulir ini. Perubahan akan dimasukkan ke daftar artikel JSON dan perlu disimpan.

Setelah mengubah daftar artikel, klik Simpan Perubahan di bagian Konten Website. Untuk pengunjung umum, konten yang disimpan di sini hanya tersimpan pada browser/perangkat ini sampai backend bersama disiapkan.

4. Integrasi Backend Google

Masukkan URL Web App Google Apps Script yang berakhiran /exec dan token admin yang Anda buat sendiri di Script Properties. Token hanya disimpan pada browser ini. Jangan pernah memasukkannya ke file publik atau repository.

Agar semua pengunjung membaca konfigurasi terbaru, isi juga window.ABUADZKA_BACKEND_URL di awal config.js dengan URL Web App tersebut, lalu deploy ulang website. Pembacaan publik menggunakan JSONP. Jika tes penyimpanan gagal karena kebijakan lintas domain, backend perlu diproxy melalui hosting atau disesuaikan dengan metode autentikasi yang mendukung CORS.

5. Simpan dan Publikasikan

Simpan JSON sebagai cadangan secara berkala. Untuk menerbitkan perubahan ke semua pengunjung, file konfigurasi perlu diperbarui di hosting atau website perlu dihubungkan ke backend bersama (misalnya Apps Script + Google Sheets). Penyimpanan browser tidak menyinkronkan perubahan antarperangkat.

Keamanan: jangan memasukkan password Google, token, API key, atau informasi rahasia ke editor ini. Login admin dan backend bersama harus dikonfigurasi sebelum panel ini dibuka untuk umum.
